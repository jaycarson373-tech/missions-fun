# Missions

**Find the job. Bring the proof.** A separate GTA VI community bounty-board frontend. Recommended ticker **$MISSIONS** (not deployed); domain **missions.fun** is an owner-suggested name, ownership/availability unverified.

## Run

`npm ci`, `npm run dev` → http://localhost:4537. `npm run typecheck`, `npm test`, `npm run build`.

## Delivered

- Original orange mission M logo, SVG and 1024×1024 PNG, favicon, 1500×500 X banner.
- Distinct dark field-map hero and warm paper bounty board; original vector route, road, camera and evidence-file graphics.
- Six proposed briefs with search/category/saved/open-only filters and an honest empty state for funded missions.
- Brief dialogs, evidence checklist, validated proof draft download, exact 2,550,000-token threshold calculator.
- Responsive layouts, keyboard dialog support, reduced motion, route-animation pause, social metadata.

This build contains no wallet connection, token mint, backend, real submission, funded bounty or payout. A calculator input cannot establish eligibility. See [backend handoff](docs/BACKEND-HANDOFF.md), [launch kit](docs/LAUNCH-KIT.md), and [release evidence](docs/RELEASE.md).
