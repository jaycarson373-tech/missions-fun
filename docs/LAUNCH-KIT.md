# BOUNTY — launch copy

Name: BOUNTY. Proposed ticker: BOUNTY. Mint, X handle and new domain not assigned. Existing preview stays on missions-fun.vercel.app.

## X bio
Player-created GTA VI challenges. Record the run. Submit the proof. AI-assisted review and community-funded bounties. Building now.

## Pump description
BOUNTY turns player-created GTA VI challenges into community bounties. Creators define the objective and proof requirements; players submit recorded gameplay for AI-assisted review. Non-wagered reward pools fund accepted runs. The current preview includes challenge and proof drafts; verification and payouts are not live.

## Launch thesis
GTA players already invent their own challenges. BOUNTY gives each one a clear brief, a clip submission and a review trail. Escape a pursuit, land a stunt or beat a route time. Creators set the rules before entries open; players bring the footage. AI checks the evidence, with human review for uncertain results. Sponsors and communities fund rewards without player wagers.

The current 2.55M-token eligibility requirement is retained. Gameplay mechanics must be verified before publishing funded challenges. No official Rockstar or Take-Two affiliation.
